# TiViLook (Samsung Tizen TV — Этап 3Б)

Приложение TiViLook для Samsung Smart TV (Tizen 2.4.0+ / аппаратный плеер AVPlay).

- **Этап 3Б:** модуль `tester.js` — «Тест каналов» с 3-колоночным выравниванием и полосами прогресса, проверкой в фоне (верхний баннер), скрытием мёртвых каналов, кнопками «Пересканировать (N)» и «Вернуть скрытые (N)».
- **Включает всё из Этапов 1, 2 и 3А:** открытый каталог, менеджер плейлистов (URL и USB), 6 тем оформления, Ambilight, формат видео, Избранное, быстрый таймаут 5.5с и приоритет HTTP-зеркал.
- **Пульт ТВ:** `1` / `MENU` / `TOOLS` — Темы и настройки, `2` — Тест каналов, `Синяя` — Плейлисты, `Жёлтая` / `0` — `★ Избранное`, `Зелёная` — следующее зеркало, `Красная` — обновить плейлист, `▶` / `INFO` — окно Info, двойной `Назад` — выход.
