# TiViLook (Samsung Tizen TV — v1.0)

Полноценное IPTV-приложение TiViLook для Samsung Smart TV (Tizen 2.4.0+ / аппаратный плеер AVPlay).

- **Плейлисты:** открытый каталог + свои плейлисты — отправка со смартфона по зашифрованному **QR-коду** (`qr.html` через GitHub Pages), ввод по ссылке URL или импорт `.m3u` с USB-флешки.
- **Темы и интерфейс (`themes.js`):** все 6 тем TiViLook, 3 уровня прозрачности, Ambilight, формат изображения, часы и автоскрытие меню.
- **Тест каналов (`tester.js`):** 3-колоночный дизайн с полосами прогресса, фоновая проверка, скрытие нерабочих, пересканирование и возврат скрытых.
- **Телепрограмма EPG (`epg.js`):** потоковый разбор `.xml.gz` без перегрузки ОЗУ ТВ, показ в OSD и Info, полное расписание и своя ссылка XMLTV.
- **Пульт ТВ:** `OK` / `◀` — каналы, группы и плейлисты, `1` / `MENU` / `TOOLS` — Темы и настройки, `2` — Тест каналов, `3` / `GUIDE` — Телепрограмма EPG, `4` — Добавить по QR-коду, `Синяя` — Плейлисты, `Жёлтая` / `0` — `★ Избранное`, `Зелёная` — следующее зеркало, `Красная` — обновить плейлист, `▶` / `INFO` — окно Info, двойной `Назад` — выход.
