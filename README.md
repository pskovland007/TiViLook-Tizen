# TiViLook (Samsung Tizen TV — тестовая сборка)

Минимальная тестовая сборка TiViLook для проверки работы на телевизоре Samsung Smart TV (Tizen 2.4+ / AVPlay).

- **Сборка:** запускается автоматически в GitHub Actions и публикует готовый `TiViLook-test.wgt` во вкладке **Releases**.
- **Пульт ТВ:** `▲ / ▼` — переключение каналов, `OK` — список каналов / запуск, `▶` или `INFO` — окно Info и журнал AVPlay, `◀` — скрыть/открыть панель, двойной `Назад` — выход.
