# TiViLook (Samsung Tizen TV — Этап 3В)

Приложение TiViLook для Samsung Smart TV (Tizen 2.4.0+ / аппаратный плеер AVPlay).

- **Этап 3В:** модуль `epg.js` — облегчённая телепрограмма EPG с потоковой распаковкой `.xml.gz` (не забивает ОЗУ Tizen 2.4.0), автоматическим чтением `url-tvg` и `tvg-id` из плейлиста, показом текущей/следующей передачи в OSD и окне Info, полным расписанием канала и вводом своей ссылки XMLTV.
- **Включает всё из Этапов 1–3Б:** открытый каталог, менеджер плейлистов (URL и USB), 6 тем оформления, Ambilight, Тест каналов с 3-колоночными полосами прогресса, Избранное, быстрый таймаут 5.5с и приоритет HTTP-зеркал.
- **Пульт ТВ:** `1` / `MENU` / `TOOLS` — Темы и настройки, `2` — Тест каналов, `3` / `GUIDE` — Телепрограмма EPG, `Синяя` — Плейлисты, `Жёлтая` / `0` — `★ Избранное`, `Зелёная` — следующее зеркало, `Красная` — обновить плейлист, `▶` / `INFO` — окно Info, двойной `Назад` — выход.
