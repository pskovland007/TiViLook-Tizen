# TiViLook (Samsung Tizen TV — Этап 1)

Приложение TiViLook для Samsung Smart TV (Tizen 2.4.0+ / аппаратный плеер AVPlay).

- **Этап 1:** открытый каталог + встроенная Tizen-база (HTTP и проверенные CDN), категории, «★ Избранное», сохранение последнего канала, авто-откат `HTTPS → HTTP` и резервные зеркала.
- **Пульт ТВ:** `OK` / `◀` — каналы и группы, `▲ / ▼` — листать/переключать, `CH+ / CH-` — быстрая прокрутка по страницам в списке, `▶` / `INFO` — окно Info и журнал, **Жёлтая кнопка** (или `0`) — `★ Избранное`, **Зелёная** — следующее зеркало, **Красная** — обновить каталог, двойной `Назад` — выход.
