# TiViLook (Samsung Tizen TV — Этап 3А)

Приложение TiViLook для Samsung Smart TV (Tizen 2.4.0+ / аппаратный плеер AVPlay).

- **Этап 3А:** меню «Темы и настройки» (все 6 тем TiViLook, 3 уровня прозрачности, подсветка рамки Ambilight, формат изображения AVPlay, часы, автоскрытие меню) в отдельном модуле `themes.js`.
- **Включает всё из Этапов 1 и 2:** открытый каталог, менеджер плейлистов (URL и USB), Избранное, быстрый таймаут 5.5с и приоритет HTTP-зеркал.
- **Пульт ТВ:** `1` / `MENU` / `TOOLS` (или вкладка `Плейлисты → ⚙ Темы и настройки`) — открыть настройки, `Синяя` — плейлисты, `Жёлтая` / `0` — `★ Избранное`, `Зелёная` — следующее зеркало, `Красная` — обновить плейлист, `▶` / `INFO` — окно Info, двойной `Назад` — выход.
