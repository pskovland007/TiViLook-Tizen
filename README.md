# TiViLook (Samsung Tizen TV — Этап 2)

Приложение TiViLook для Samsung Smart TV (Tizen 2.4.0+ / аппаратный плеер AVPlay).

- **Этап 2:** менеджер плейлистов (добавление своих листов по ссылке URL или с USB-флешки, удаление своих листов, сохранение оригинальных групп), ускоренный таймаут переключения зеркал (5.5с вместо 13с) и приоритет HTTP-потоков перед HTTPS.
- **Пульт ТВ:** `OK` / `◀` — каналы, группы и плейлисты (`◀ / ▶` между вкладками), **Синяя кнопка** — сразу в «Плейлисты», **Жёлтая** (или `0`) — `★ Избранное`, **Зелёная** — следующее зеркало, **Красная** — обновить текущий плейлист, `▶` / `INFO` — окно Info, двойной `Назад` — выход.
