# TiViLook — Samsung Tizen TV (Handoff Context v1.0)

## 1. Целевое устройство и окружение
- **Телевизор:** Samsung UE49KU6670 (2016)
- **ОС:** Tizen 2.4.0 (старый WebKit, ограниченное ОЗУ, устаревшие корневые SSL-сертификаты, нет TLS 1.3)
- **Репозиторий GitHub:** `pskovland007/TiViLook-Tizen` (Public, ветка `main`)
- **GitHub Pages (для QR-формы):** `https://pskovland007.github.io/TiViLook-Tizen/qr.html`
- **Сборка:** GitHub Actions (`.github/workflows/build-tizen.yml`) — проверка `config.xml` через `python3`, проверка всех `*.js` через `node --check`, упаковка в `TiViLook-tizen.wgt`, публикация в Releases.
- **Установка на ТВ:** ПК используется для работы с GitHub, готовый `.wgt` переносится на Android-смартфон и ставится на ТВ по Wi-Fi (Developer Mode ON, IP телефона в `12345`) через Apps2Samsung / TV Installer.
- **ID приложения (НЕ менять, чтобы обновления ставились поверх):**
  - `widget id`: `http://tivilook.local/TiViLook`
  - `tizen:application id`: `tvlkTizen1.TiViLook`, `package`: `tvlkTizen1`, `required_version="2.3"`
  - Текущая версия в `config.xml`: `1.0.0`

## 2. Жёсткие технические ограничения Tizen 2.4.0
1. **Только строгий ES5 во всех JS-файлах (`*.js` и скрипт в `qr.html`):** запрещены `let`, `const`, стрелочные функции `=>`, шаблонные строки `` ` ``, `fetch()`, `class`, `async/await`, `Promise`. Использовать только `var`, `function`, `XMLHttpRequest`.
2. **Tizen 2.4 WebKit-совместимый CSS:** запрещены CSS-переменные `var(--...)`, `gap:`, CSS Grid, современные фильтры. Использовать фиксированный viewport `1920x1080`, абсолютное позиционирование и `inline-block`.
3. **Плеер:** нативный аппаратный `webapis.avplay` (`<object id="av-player" type="application/avplayer">`) + фолбэк `<video id="html5-player">` для просмотра в десктопном браузере.
4. **SSL на Tizen 2.4.0:** часть современных HTTPS-серверов (новый Let's Encrypt / TLS 1.3) отдаёт `PLAYER_ERROR_CONNECTION_FAILED`.
   - Работают стабильно: открытые `HTTP`-потоки и классические CDN (`lotus.stingray.com`, `beltelecom.by`, `cdn2.ntv.ru`, `stream8.cinerama.uz`, `cloudfront.net`, `amagi.tv`, `roku.com`).
   - Очередь попыток для открытого каталога: реальные HTTP-зеркала → проверенные HTTPS CDN → синтетический откат `https:// → http://` → остальные HTTPS.
   - Для пользовательских плейлистов сначала всегда пробуется точный URL из листа (сохранение токенов).
   - Жёсткий таймаут `prepareAsync` — `5.5 сек` (с защитой `playSessionId` от гонки коллбэков).
5. **Память (ОЗУ и localStorage):** избегать загрузки десятков МБ текста целиком; распаковка `.xml.gz` в `epg.js` идёт потоково чанками по ~48 КБ с `setTimeout`-паузами; списки каналов и групп рендерятся оконным методом (по 7–9 видимых строк).

## 3. Архитектура файлов (модульная)
- `config.xml` — манифест Tizen (`internet`, `tv.inputdevice`, `application.launch`, `filesystem.read`).
- `index.html` — разметка 1920×1080 (плеер, часы, индикатор сигнала, левая панель, правая панель Info, модалки: ввод URL, подсписки USB/удаления, Темы и настройки, Тест каналов + фоновый баннер, Телепрограмма EPG + ввод URL EPG, QR-код, OSD, Toast, Splash с `icon.png` без текста).
- `style.css` — базовые стили (1173 строки, чистый Tizen 2.4 CSS).
- `themes.js` (`window.TiViThemes`, 467 строк) — 6 тем TiViLook («Материал Дизайн», «Неон», «Амолед Блэк», «Монохром», «Ретро», «Карусель»), 3 уровня прозрачности, Ambilight (выкл/цвет темы/спектр), формат видео AVPlay, часы, автоскрытие бокового меню. Ключ хранения: `tivilook_tizen_v3_settings`.
- `tester.js` (`window.TiViTester`, 854 строки) — «Тест каналов» с 3-колоночным выравниванием (название / полоса прогресса / табличные счётчики `✓` и `✕`), фоновый режим (верхний баннер), скрытие нерабочих (`tivilook_tizen_v3_auto_hidden`), пересканирование и возврат скрытых. Параллельность: 3 воркера, XHR abort после подтверждения заголовков/первого сегмента, без `Range`.
- `epg.js` (`window.TiViEpg`, 1243 строки) — потоковый ES5 RFC 1951/1952 Gunzip + инкрементальный XMLTV-парсер (фильтрует только загруженные каналы в окне `-2ч..+26ч`), автоподхват `url-tvg`/`tvg-id`/`tvg-name`, показ в OSD и окне Info, полное расписание, ввод своей ссылки. Ключи: `tivilook_tizen_v3_epg_cfg`, `tivilook_tizen_v3_epg_cache`.
- `qr.js` (`window.TiViQr`, 885 строк) — офлайн-генератор QR (ISO/IEC 18004 v1..v10, EC Level L) на `<canvas>`, сквозное шифрование RC4-drop256 + 8-байтная соль + Base64URL ключом из `#hash`, автоподбор доступного реле (`ntfy.sh`, `jsonblob.com`, `kvdb.io`), приём URL и файлов `.m3u` + опциональный EPG URL.
- `qr.html` (431 строка) — мобильная веб-форма для смартфона (хостится на GitHub Pages), симметричное шифрование RC4-drop256 в браузере.
- `app.js` (`window.TiViApp`, 2481 строка) — ядро: открытый каталог (~60 встроенных Tizen-проверенных + фоновая загрузка 13 открытых M3U с дедупликацией и фильтрацией `cast`/региональных/политических в «Прочее»), менеджер плейлистов (Основной + свои URL/USB/QR), Избранное, движок AVPlay, пульт Samsung. Префикс хранения: `tivilook_tizen_v3_`.
- `icon.png` — 512×512, 16-лучевой разноцветный глаз TiViLook без текста.
- `.github/workflows/build-tizen.yml` — автосборка и публикация релиза.

## 4. Пульт Samsung (актуальные привязки)
- `OK` / `◀` — боковое меню (`Плейлисты` | `Группы` | `Каналы`, переключение `◀ / ▶`)
- `▲ / ▼` — листать список / переключать каналы на эфире; `CH+ / CH-` — постраничная прокрутка в списке
- `1` / `MENU` / `TOOLS` — Темы и настройки
- `2` — Тест каналов
- `3` / `GUIDE` — Телепрограмма EPG
- `4` — Добавить плейлист по QR-коду
- `Синяя` — вкладка «Плейлисты» | `Жёлтая` / `0` — `★ Избранное` | `Зелёная` — следующее зеркало | `Красная` — обновить текущий плейлист
- `▶` / `INFO` — окно Info + журнал событий | `PRE-CH` — предыдущий канал | двойной `Назад` — выход

## 5. Правила работы в новом чате
- **НЕ писать длинный исходный код прямо в чат** — всегда упаковывать обновлённые файлы в готовый `.zip`-архив (проверяя XML и синтаксис всех `*.js` перед упаковкой).
- Сохранять модульную структуру: по возможности править конкретный модуль (`themes.js`, `tester.js`, `epg.js`, `qr.js`, `app.js`, `style.css`, `index.html`) точечно, не переписывая весь проект с нуля.
- Все доработки проверять на строгий ES5 и совместимость с Tizen 2.4.0 WebKit.
